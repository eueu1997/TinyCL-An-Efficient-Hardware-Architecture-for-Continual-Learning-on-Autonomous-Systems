# docs: figure del mini-progetto Batch Normalization

## Contenuto e scopo

[bn_forward.png](bn_forward.png) e [bn_backward.png](bn_backward.png) illustrano
i passaggi della normalizzazione; [results.png](results.png) e' il risultato
storico incorporato nel README originario; [prova.png](prova.png) e' un ulteriore
grafico di prova. Sono immagini, non sorgenti del modello o serie numeriche.

## Utilizzo

Aprirle nel visualizzatore immagini o nella preview Markdown del
[README](../README.md). Per rigenerare un confronto occorrono dati CSV, ambiente
e configurazione coerenti con la versione del codice che ha prodotto la figura.
Il main attuale visualizza grafici ma non garantisce di sovrascrivere questi
quattro file. Conservare attribuzioni e licenze del progetto in caso di riuso.

## Possibili bug e limiti rilevati

Nessun codice eseguibile qui. Le immagini non riportano un manifest completo di
seed, revisione e dati e non dimostrano la correttezza degli esperimenti interi
attivi nel main attuale. Non ricavare valori numerici esatti dai soli pixel.
